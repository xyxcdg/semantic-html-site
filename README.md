# 墨记 · 极简云笔记（语义化标签示例站点）

一个用于「运用语义化标签实现目标网站」作业的示例站点：纯 HTML5 + CSS，
不依赖任何框架与外部资源，双击 `index.html` 即可在浏览器本地预览。

## 语义化标签使用

| 标签 | 用途 |
| --- | --- |
| `<header>` | 页头（Logo + 导航） |
| `<nav>` | 主导航 / 页脚导航 |
| `<main>` | 页面主内容 |
| `<section>` | Hero / 功能 / 界面 / 价格 / FAQ 等分区 |
| `<article>` | 功能卡片、价格方案等独立内容单元 |
| `<aside>` | 界面展示区的侧栏数据 |
| `<figure>` / `<figcaption>` | 编辑器界面预览与图注 |
| `<footer>` | 页脚 |
| `<details>` / `<summary>` | 可折叠的常见问题 |
| `<dl>` / `<dt>` / `<dd>` | 侧栏统计数据 |

## 目录

```
index.html   页面结构（语义化标签）
styles.css   样式（响应式布局）
README.md    说明文档
```

## 本地预览

直接用浏览器打开 `index.html`，或在该目录运行：

```bash
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 说明

- 布局：CSS Grid + Flexbox，桌面端两栏、移动端单栏自适应。
- 视觉：米白背景 + 墨绿主色，模拟真实产品落地页质感。
- 零外部依赖：字体使用系统字体，图标以内联字符/CSS 实现，保证离线可用。
